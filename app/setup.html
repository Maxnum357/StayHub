ข้อมูลตั้งค่านี้เก็บบนเครื่องหลัก เปิดหน้านี้ได้จากเมนู Settings ของ StayHub บนเครื่องหลักเท่านั้น

1 · ข้อมูลที่พัก
2 · Google Sheets และ Drive

หากยังไม่พร้อม สามารถปิดไว้เพื่อบันทึกข้อมูลและพิมพ์บนเครื่องก่อน แล้วกลับมาตั้งค่าภายหลังได้

ขั้นตอนติดตั้ง Apps Script สำหรับบัญชีของที่พัก
  1. กรอกลิงก์ด้านบน แล้วกดดาวน์โหลดสคริปต์
  2. เปิด Google Apps Script สร้างโปรเจคใหม่ วางโค้ดจากไฟล์ StayHub-Google.gs ทั้งหมด
  3. เลือกฟังก์ชัน setupStayHub แล้วกด Run และให้สิทธิ์บัญชีเจ้าของชีต/โฟลเดอร์
  4. Deploy → New deployment → Web app เลือก Execute as: Me และ Who has access: Anyone การรับคำขอจะตรวจรหัสลับที่สร้างเฉพาะเครื่องนี้
  5. คัดลอก URL ลงท้าย /exec มาวางด้านล่าง แล้วกดทดสอบ ห้ามส่งไฟล์สคริปต์ซึ่งมีรหัสลับให้ผู้อื่น
  6. ฟังก์ชัน OCR ต้องเปิด Drive API ใน Google Cloud project ที่เชื่อมกับ Apps Script หากไม่ใช้ OCR สามารถข้ามได้

PDF รุ่นพกพาสร้างผ่าน Google Docs ใช้แบบฟอร์มมาตรฐาน StayHub ส่วนสัญญาเช่าต้องใช้ฉบับที่ที่พักตรวจสอบแล้ว

3 · QR รับเงิน

ใช้ QR ของบัญชีที่พักเท่านั้น ตรวจชื่อผู้รับในแอปธนาคารก่อนใช้จริง ระบบไม่ได้ตรวจเงินเข้าอัตโนมัติ

เว้นว่างเพื่อปิด QR จนกว่าจะตั้งค่า รองรับ Payload Thai QR พร้อม CRC ที่ถูกต้อง

4 · เชื่อมอุปกรณ์อื่นและสำรองข้อมูล

คอมและแท็บเล็ตต้องอยู่ Wi-Fi เดียวกัน อนุญาต StayHub ใน Windows Firewall เฉพาะเครือข่าย Private ใช้ไฟล์ Allow-Private-Network.cmd ในโฟลเดอร์ที่ติดตั้ง (ต้องใช้สิทธิ์ผู้ดูแล)
