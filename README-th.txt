StayHub 1.0.0 — รุ่นติดตั้งสำหรับทดสอบ Windows 10/11 x64

1. เปิด StayHub-Setup-1.0.0.exe ติดตั้งในบัญชี Windows ของผู้ใช้
2. เปิด StayHub จาก Desktop จะเปิดหน้าตั้งค่าครั้งแรกอัตโนมัติ
3. ตั้งชื่อที่พัก เลขห้อง ราคาต่อคืน รหัสประวัติ 6 หลัก
4. เชื่อม Sheets/Drive ตามคำแนะนำในหน้า Setup ทดสอบก่อนใช้จริง
5. บันทึกแล้วเปิด StayHub ต้องติดตั้งไดรเวอร์เครื่องอ่านบัตรของผู้ผลิตด้วย
6. เปลี่ยนค่าภายหลัง: ไอคอน StayHub ข้างนาฬิกา Windows → Settings
7. ใช้แท็บเล็ตใน Wi-Fi เดียวกัน: คัดลอกลิงก์จากหน้า Settings
   เปิด Allow-Private-Network.cmd ถ้าติด Firewall (สิทธิ์ผู้ดูแล)
8. ปิดโปรแกรมทั้งหมด: ไอคอนข้างนาฬิกา → Exit StayHub

ข้อมูลและรหัสเชื่อมต่ออยู่ที่ %LOCALAPPDATA%\StayHub\data
ปิดโปรแกรมก่อนคัดลอกโฟลเดอร์นี้เพื่อสำรอง เก็บสำรองอย่างปลอดภัย
ถอนการติดตั้งจะไม่ลบข้อมูล ต้องใช้บัญชี Windows เดิมในการเปิดข้อมูลเดิม
ไม่ต้องติดตั้ง Node หรือ Python เพิ่ม รุ่นนี้ใช้ Google Docs สร้าง PDF
แบบ PDF มาตรฐาน ไม่ใช่แบบ Canva ของที่พักเดิม สัญญารายเดือนต้องแนบฉบับ
ที่ที่พักตรวจสอบเอง การพิมพ์จากหน้าเว็บทำได้ในเครื่อง
QR ต้องตั้ง Payload บัญชีของที่พัก และตรวจชื่อผู้รับด้วยแอปธนาคาร
การยืนยันรายการ/หมดเวลาหน้า QR ไม่ได้ยืนยันว่าได้รับเงินแล้ว

รุ่นนี้ยังไม่ได้ลงลายเซ็นผู้เผยแพร่ดิจิทัล และยังไม่ผ่านการทดสอบ
บน Windows ใหม่ที่ไม่เคยติดตั้งโปรเจคมาก่อน จึงเป็นรุ่นทดลองติดตั้ง
ก่อนขายจริงต้องจัดทำเงื่อนไขการใช้ ใบอนุญาต นโยบายข้อมูล และการอัปเดต
