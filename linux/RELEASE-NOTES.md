# stayhub Linux Server v0.3.0

- Ubuntu/Debian systemd installer for x86_64 and ARM64, official Node.js download with SHA-256 verification.
- Current daily/monthly registration UI, deposit balance, signature and Canva PDF support.
- Numeric Buddhist date + customer name PDF filenames; recreates deleted/trashed Drive PDFs without restoring old files.
- First-run setup through an authenticated localhost page/SSH tunnel; per-install Google/QR/PIN configuration.
- Windows USB card-reader bridge, persistent data directory, service management and backup command.
- Private repository; authenticate to GitHub before cloning/downloading. No customer records, access keys or merchant payment details included.
- One shared active registration; Windows desktop automation/AirPlay receiver are separate components. Google and Drive-only photos require internet.
